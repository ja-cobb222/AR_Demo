# AR_Demo

A personal AR prototype built in Unity, exploring real-surface object placement and interaction using AR Foundation.

## What this is

I built this project to explore augmented-reality interaction patterns on real-world surfaces — the same kind of AR/Unity work I did during a software engineering internship at Evu, where I built a cross-platform AR prototype for real-time object placement and interaction.

## Features

- Real-world surface detection via AR Foundation / ARKit
- Tap-to-place object spawning on detected surfaces
- Grab/drag interaction using AR raycasts and rigidbody physics
- "Through" and stacking interactions between placed objects
- Editor auto-spawn for faster iteration without a physical device

## Tech stack

Unity, C#, AR Foundation, ARKit, URP (Universal Render Pipeline)

## Status

Personal exploration project — a Unity/AR Foundation demo of real-surface interaction mechanics.
